# 📊 Agregador de Dados para Imposto de Renda no Excel

> Projeto prático desenvolvido como parte do desafio da plataforma **DIO (Digital Innovation One)** para organização e validação de informações essenciais da declaração do Imposto de Renda.

---

## 🎯 Objetivo do Projeto

Desenvolver uma ferramenta prática, interativa e robusta no Microsoft Excel para auxiliar contribuintes na consolidação de rendimentos, despesas dedutíveis e bens, garantindo consistência através de validações automáticas, menus navegáveis e links rápidos.

---

## 🛠️ Recursos e Funcionalidades Construídas

* **Navegação Interativa:** Menus dinâmicos com botões de navegação para alternar rapidamente entre abas (Rendimentos, Despesas, Bens, Resumo).
* **Validação de Dados:** Menus suspensos (listas de validação) para categorização estrita de receitas e despesas, evitando erros de digitação.
* **Fórmulas Condicionais e de Busca:**
  * `SOMA` e `SOMASE` / `SOMASES` para totalizar rendimentos e deduções por categoria.
  * `CONT.SE` / `CONT.SES` para auditoria e contagem de lançamentos efetuados.
  * `PROCV` para consultar e retornar tabelas de alíquotas vigentes do IR.
* **Formatos de Data e Texto:** Tratamento de datas (`ANO`, `MÊS`, `DATADIF`) para controle temporal das movimentações.
* **Dashboard / Painel de Resumo:** Visão consolidada da base de cálculo estimada e saldo parcial.
